Amphi: your EPITA timetable, in English

EPITA’s official timetable, ZEUS, is in French and made for a desktop screen. For an exchange student, that makes it hard to tell a lecture from a lab, or to check your next room on the way there.

Amphi reads the calendar file ZEUS exports and turns it into a phone app in English. It opens straight to your next class and works offline. There’s no login and no server. Everything stays in your own browser.

Now / Next

Home opens on the class that’s on and the one after it, with the room. Tap it to jump to that day.

French, explained

Each class card translates the ZEUS words it contains, whole phrases first.CM = Lecture · Rattrapages = Resits

Red “now” line

Like a phone calendar: a line on today’s timetable shows where you are in the day.

Friends

See where a friend’s timetable says they are, and when you’re both free. Shared links never include rooms and never reach a server.

Free rooms

Rooms with no class booked now or in the next 1–3 hours, at Kremlin-Bicêtre and Villejuif.

Change alerts

A weekly data update fixes moved classes and room changes, and warns you about anything in the next 7 days.

How it’s built

  • AppPlain JavaScript, HTML and CSS. No framework, no server.
  • DataParses ZEUS calendar (.ics) exports; a Node script builds the weekly room and update files.
  • OfflineService worker and web app manifest, so it installs to the home screen.
  • TestingNode test runner for the logic, Playwright for phone-sized browser tests.
  • ShippingGitHub Pages, with GitHub Actions running every test on each push.
